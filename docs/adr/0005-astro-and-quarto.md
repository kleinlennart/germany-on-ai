# Astro for the Explorer, Quarto for the Report

The Explorer is built with Astro, a static-first framework that adds interactivity only where a page needs it. The Report and methods supplements are written in Quarto, which produces a print PDF and a web version from one source with proper citations. Both read the same data exports. Quarto alone would cover the Report but limits the Explorer's interface; a full JavaScript framework alone would make the PDF report and citations harder.
